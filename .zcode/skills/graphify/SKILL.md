# Graphify

В проекте есть локальный граф `graphify-out/graph.json`. Используй его перед обычным поиском по коду.

1. Для вопроса по коду: `graphify query "<конкретный вопрос>" --budget 2000`.
2. Для связи двух компонентов: `graphify path "<A>" "<B>"`.
3. Для конкретного класса или функции: `graphify explain "<название>"`.
4. Для последствий изменения: `graphify affected "<название>"`.
5. Открывай только найденные графом файлы и нужные строки. Если граф не нашёл совпадение, сузь вопрос до имени символа, затем при необходимости используй обычный поиск.
6. После изменения кода: `graphify update .`. AST-обновление локальное и не расходует API-лимиты.

Для общего обзора архитектуры читай `graphify-out/GRAPH_REPORT.md`. Полную документацию смотри в `.claude/skills/graphify/SKILL.md` только когда базовых команд недостаточно.

Не удаляй `graphify-out/`, `.claude/` или `AGENTS.md` при очистке проекта: это рабочая система экономии токенов, а не мусор.
