# HexShard 1.16.2

- Медиа снова грузится у собеседника: фото, видео и голосовые берут ключ шифрования из ID диалога, а не из строки чата — чаты, созданные старыми версиями, больше не ломают скачивание молча. Старые чаты лечатся сами при следующем сообщении.
- Отправка тоже надёжнее: сообщения и медиа к собеседнику больше не застревают «в ожидании ключа» из-за той же ошибки.
- Если медиа всё же не загрузилось, теперь показывается причина коротким кодом (KEY / DECRYPT / HTTP…) и нормальная подпись по-русски вместо молчаливой иконки.
- Тексты медиа и превью в списке чатов — по-русски и без квадратиков-эмодзи.
- Пропущенные звонки в списке чатов — без квадратиков вместо значка телефона.
- Заметки обновлений больше не показывают старую версию: файл заметок теперь обновляется с каждым релизом.
