# HexShard 1.16.4

- Криптография вложений выровнена с сообщениями: медиа шифруется тем же правилом выбора ключа, что и текст — расхождение, из-за которого текст доходил, а медиа падало с DECRYPT, устранено.
- Приёмник пробует при расшифровке все варианты ключей, включая старые форматы и ключ «с сервера» — старые вложения из других версий тоже получают шанс.
- Если медиа всё же не расшифровалось, ошибка теперь несёт отпечатки ключей и код — по одному скриншоту можно точно назвать виновника.
- Зависшая загрузка не может выдать «пустой» файл, кэш не отравляется при сбоях, пересылка не роняет приложение.
