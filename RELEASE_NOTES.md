# HexShard 1.10.0

- Выбранный номер +999 больше не заменяется другим номером: занятый номер отклоняется с понятной ошибкой.
- Ручной выбор номера при регистрации теперь проходит серверную резервацию перед активацией.
- Убраны локальные обходы при недоступных серверных функциях резервации и активации.
- Улучшена загрузка аватарок и восстановление отсутствующего профиля без изменения ключей шифрования.
- Добавлена проверка файлов обоев: размер, формат и корректное изображение.
- Независимые запросы при регистрации выполняются параллельно.
- В настройки добавлен центр обновлений с проверкой официального релиза, SHA-256 и подписи APK. Установка выполняется через системное подтверждение Android.

Обновление серверной функции резервации номера поставляется отдельной миграцией Supabase.
