# HexShard 1.13.0

- Смена номера работает: свободный номер больше не «недоступен» — любой незанятый номер можно выбрать и активировать (проверено живым тестом на сервере).
- ИИ больше не выдумывает про Ventaxis: добавлены точные факты о Ventaxis Corp и о тебе (Ventaxis — ник создателя; HexShard — только Android; никаких машин, iOS и веба).
- Режим разработчика: 7 быстрых тапов по строке «Обновления и исправления» → окно с секретной фразой. Проверка выполняется на сервере (фраза не хранится в приложении), доступ на 1 час. Внутри: тест аватарки на сервере (загрузка + удаление, ничего не остаётся), тест сигнала звонка, баны/разбаны по юзернейму со списком. Каждое действие ограничено по частоте и пишется в серверный журнал аудита.
- Требуется секрет SECRET_WORD в настройках Supabase Edge Functions — до его добавления окно фразы честно отвечает «неверная фраза».
