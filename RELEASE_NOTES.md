# HexShard 1.12.0

- Настоящие аудиозвонки 1:1 через WebRTC: кнопка звонка в чате, полноэкранный оверлей с mute, спикером и таймером, входящий звонок с рингтоном и таймаутом.
- Сигналинг звонков закрыт приватными каналами Realtime с проверкой доступа на сервере: звонить может только контакт, чужие топики отвергаются сервером (проверено живым тестом).
- Вылечено «⚠️ Corrupted message»: при смене ключей собеседника сообщения расшифровываются новым ключом, но помечаются «ключ изменился» — баннер с кнопкой «Принять» вместо тихой потери доверия. Старые битые сообщения восстанавливаются при синке, если ключи теперь подходят.
- Чат теперь называется именем собеседника у обеих сторон (было одно имя на двоих).
- Через «+» больше нельзя создать несуществующего пользователя — только поиск по юзернейму или номеру +999.
- Глобальный поиск оживлён (был сломан запросом к несуществующей колонке) и находит людей по номеру +999.
- Профили собеседников открываются, с их HexShard-номером.
- Смена номера: Настройки → тап по номеру → освободить → выбрать новый.
- Чат с ИИ удалить нельзя (только очистка); удаление обычных чатов работает надёжнее.
- Превью в списке чатов без сырой разметки: «**текст**» и мусорные теги вида <bf4> вычищены.
- ИИ отвечает с характером: исправлена температура (было 2.0 — хаос), промпты персонажей переписаны, ссылки из сообщений — только http(s), slash-команды для ИИ — просто текст.
- Кнопка «назад» закрывает чат, а не выходит из приложения.
